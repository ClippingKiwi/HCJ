# MT 일정 및 가이드 웹페이지 (0831, 팀 프로젝트)

성공적인 MT 진행을 위한 일정 및 가이드 안내 웹페이지입니다.

## 주요 내용
- MT 세부 일정표 및 장소 안내
- 예산, 준비물 체크리스트, 레크리에이션 프로그램 소개
- 팀원 간 원활한 정보 공유를 위한 웹 페이지 구성

## 파일 구성
- `index.html` : 메인 페이지
- `code.gs` : Google Apps Script (백엔드/배포용)
