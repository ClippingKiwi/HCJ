# Smart Doc Compressor

**Smart Doc Compressor**는 문서, 고화질 이미지 및 동영상 파일의 용량을 서버 업로드 없이 클라이언트(브라우저) 환경에서 안전하고 빠르게 최적화해 주는 웹 애플리케이션입니다.

---

## 💡 주요 특징

* **클라이언트 사이드 압축**: 모든 파일 처리 및 압축 작업이 사용자의 브라우저 내에서 직접 수행되어 개인정보 및 문서 보안에 안전합니다.


* **동영상 & 이미지 실시간 압축**: HTML5 Canvas와 MediaRecorder API를 통해 고화질 이미지와 비디오를 직접 재인코딩 및 리샘플링하여 용량을 절감합니다.


* **다양한 파일 포맷 지원**: 문서, 이미지, 동영상을 아우르는 광범위한 확장자를 지원합니다.


* **드래그 앤 드롭 지원**: 화면 전체 영역 및 드롭존을 통한 간편한 파일 업로드를 지원합니다.


* **비동기 대기열 처리**: 개별 파일별 독립적인 진행률 표시줄과 함께 작업 현황을 제공합니다.



---

## 📁 지원 파일 형식

| 분류 | 지원 확장자 |
| --- | --- |
| **문서 (Document)**<br> | PDF, PPT, PPTX, DOC, DOCX, HWP, HWPX

 |
| **이미지 (Image)**<br> | JPG, JPEG, PNG, WEBP, GIF

 |
| **동영상 (Video)**<br> | MP4, WEBM, MOV, MKV

 |

---

## 🛠️ 기술 스택 및 핵심 구현 (Method 1)

* **Frontend**: HTML5, CSS3, JavaScript (ES6+)


* **Design System**: Glassmorphism CSS UI, Responsive Grid


* **Image Engine**: HTML5 Canvas API (`toBlob` 최적화 및 스마트 리샘플링)


* **Video Engine**: HTML5 Video + Canvas Stream Capture (`captureStream`) + `MediaRecorder` API 비트레이트 압축



---

## 🚀 시작하기

별도의 서버 설치나 패키지 매니저(npm/yarn) 설정 없이, 브라우저만으로 즉시 실행할 수 있습니다.

1. 이 저장소를 클론하거나 다운로드합니다.
2. 프로젝트 루트 폴더에 위치한 `index.html` 파일을 웹 브라우저(Chrome, Edge, Safari 등)로 실행합니다.



---

## 📖 사용 방법

1. **파일 추가**: 메인 화면의 드롭존으로 파일(문서, 이미지, 동영상)을 끌어다 놓거나 **'파일 선택하기'** 버튼을 클릭합니다.


2. **압축 진행**: 파일이 추가되면 작업 대기열이 노출되고, 각 파일별 압축 상태가 실시간으로 업데이트됩니다.


3. **다운로드**:
* 개별 파일: 압축 완료 후 우측의 **'다운로드'** 버튼을 누르면 `compressed_원본파일명` 형태로 저장됩니다.


* 일괄 다운로드: 상단의 **'완료된 파일 모두 받기'** 버튼을 눌러 전체 결과를 다운로드할 수 있습니다.
