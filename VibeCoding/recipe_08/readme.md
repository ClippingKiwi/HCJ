# 🎬 GIF Maker - Video to GIF Web Application

**GIF Maker**는 브라우저에서 동영상 파일(MP4, WebM 등)을 간편하게 애니메이션 GIF 파일로 변환해 주는 웹 애플리케이션입니다.  
서버 전송 없이 클라이언트(브라우저) 내에서 프레임을 추출 및 합성하여 빠르게 GIF를 생성합니다.

---

## ✨ 주요 기능

- **브라우저 기반 GIF 변환**: 서버 없이 웹 브라우저 자체에서 GIF를 변환 및 생성합니다.
- **다크 모드 UI**: 유튜브 스타일의 깔끔하고 현대적인 다크 테마 디자인을 제공합니다.
- **드래그 앤 드롭 업로드**: 동영상 파일을 드래그 앤 드롭하거나 클릭하여 간편하게 업로드할 수 있습니다.
- **30 FPS 제한 최적화**: 너무 긴 변환 시간을 방지하기 위해 30 FPS 프레임 제한을 두어 빠르고 유연하게 작동합니다.
- **실시간 프로그레스 바**:
  - 변환 상태를 0%부터 100%까지 실시간 게이지로 표시합니다.
  - 변환 중에는 동영상 썸네일을 미리 볼 수 있습니다.
- **완료 후 원클릭 다운로드**: 변환이 100% 완료되면 활성화되는 다운로드 버튼을 통해 생성된 GIF를 즉시 저장할 수 있습니다.
