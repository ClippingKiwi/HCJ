# 💍 모바일 청첩장 웹 애플리케이션 (Recipe 04)

스마트폰 환경에 완벽하게 최적화된 고급스럽고 감성적인 모바일 청첩장 웹 페이지입니다.  
별도의 무거운 프레임워크나 외부 라이브러리 없이 **순수 HTML5, CSS3, JavaScript**로 구축되어 빠른 로딩 속도와 부드러운 인터랙션을 제공합니다.

---

## 📅 예식 정보
- **일시**: 2027년 6월 5일 (토) 오전 11시
- **장소**: 나나컨벤션센터 2층 플로렌스홀
- **신랑**: 루크사트 · 파르벤의 아들 **드미트리**
- **신부**: 마키아토 · 페르시카의 딸 **로렐라이**

---

## ✨ 주요 기능 및 특징

### 1. 모바일 퍼스트 최적화 (Mobile-First Layout)
- 스마트폰 화면 비율(최대 너비 450px)을 기본으로 설계되어 모바일 기기에 완벽하게 대응합니다.
- PC/태블릿 환경에서도 중앙 정렬된 스마트폰 카드 프레임 형태로 미려하게 렌더링됩니다.
- iOS/Android 노치 디자인 대응 (`viewport-fit=cover`).

### 2. 실시간 D-Day 카운트다운 애니메이션
- **타이머 기준일**: `2027년 6월 5일 오전 11:00 (KST)`
- **일(DAYS) : 시간(HOUR) : 분(MIN) : 초(SEC)** 단위 실시간 갱신.
- 1초마다 숫자가 변경될 때 부드러운 스케일 및 펄스 틱 애니메이션(`tick-animate`) 적용.
- 실시간 경과를 알리는 라이브 인디케이터(`LIVE` 깜빡임 뱃지) 및 잔여 시간 문구 실시간 출력.
- 2027년 6월 미니 캘린더 상에 예식 당일(5일 토요일) 골드 링 펄스 애니메이션 하이라이트.

### 3. 신랑 & 신부 연락처 바텀시트 모달
- "지금 신랑에게 연락하기", "지금 신부에게 연락하기" 버튼 터치 시 하단에서 부드럽게 올라오는 바텀시트 모달.
- 모바일 기기에서 터치 한 번으로 **전화 걸기(`tel:`)** 및 **문자 보내기(`sms:`)** 바로 연결.

### 4. 갤러리 및 풀스크린 라이트박스 (Lightbox)
- 웨딩 스냅 사진 5종(`함께1`, `함께2`, `함께3`, `신랑`, `신부`) 감성 그리드 배치.
- 사진 클릭 시 전체 화면 라이트박스 뷰어 오픈.
- 모바일 좌우 **터치 스와이프(Touch Swipe)** 제스처 지원, 좌우 화살표 버튼, 키보드 방향키 및 ESC 닫기 지원.

### 5. 오시는 길 & 내비게이션 길찾기
- 나나컨벤션센터 2층 플로렌스홀 위치 및 약도 카드.
- **네이버 지도**, **카카오 맵**, **티맵(T MAP)** 원클릭 길찾기 바로가기 연동.
- 지하철(강남역 3번 출구), 버스 노선, 자가용 및 주차 안내 상세 수록.

### 6. 마음 전하시는 곳 (축의금 계좌 및 복사 기능)
- 신랑측 / 신부측 분리된 아코디언 인터랙션.
- **[복사]** 버튼 클릭 시 클립보드 복사(`navigator.clipboard` 및 fallback 지원).
- 복사 완료 시 하단에 세련된 토스트(Toast) 메시지 알림 표시.

### 7. 감성 인터랙션 & 효과
- **벚꽃 꽃잎 파티클 캔버스**: 화면 위에서 은은하게 흩날리는 2D Canvas 꽃잎 애니메이션 (우측 상단 플로팅 버튼으로 온/오프 가능).
- **스크롤 리빌 효과**: Intersection Observer API를 활용한 부드러운 페이드인 슬라이드업 효과.
- **공유하기**: 청첩장 URL 복사 버튼 및 모바일 웹 공유 API(`navigator.share`) 연동.

## 🚀 실행 방법

### 방법 1. 웹 브라우저에서 바로 열기 (가장 간단한 방법)
1. 파일 탐색기에서 `index.html` 파일을 더블 클릭합니다.
2. 기본 웹 브라우저(Chrome, Edge, Safari 등)에서 즉시 확인하실 수 있습니다.
> **모바일 화면 미리보기 Tip**: PC 브라우저에서 `F12`를 누른 후 `Ctrl + Shift + M` (또는 기기 툴바 아이콘)을 누르면 실제 스마트폰 화면과 동일하게 확인하실 수 있습니다.

### 방법 2. 로컬 웹 서버로 실행하기
로컬 웹 서버 환경에서 실행하고 싶으신 경우:

```bash
# Python 내장 서버 실행 (Python 3 기준)
python -m http.server 8080

# 또는 Node.js npx serve 실행
npx serve .
```

브라우저에서 `http://localhost:8080`으로 접속합니다.
