# 프로필 소개 웹페이지 (0727)

7월 27일 작성. 템플릿 없이 자유롭게 디자인한 개인 프로필 소개 페이지입니다.

## 주요 내용
- 프로필 카드형 레이아웃 (이름, 소개, 연락처)
- Google Fonts(Noto Sans KR, Poppins) 적용
- 다크모드 등 토글 인터랙션 (`toggle.js`)

## 파일 구성
- `index.html` : 메인 페이지
- `introduce1.css` : 스타일시트
- `toggle.js` : 토글 인터랙션 스크립트
- `img/` : 프로필 이미지

## 실행 방법
`index.html` 파일을 브라우저에서 열면 바로 확인이 가능합니다.
